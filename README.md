# 🐾 Moni 데스크탑 AI 비서 펫 (Developer Update Log)

  - 기존의 단조로웠던 스파클(반짝이) 토글 아이콘을 개량하여, 상태창이 활성화되면 우측 퀵 컨트롤 버튼의 아이콘이 스마트하게 **X(닫기) 형태의 이미지**로 교차 전환되도록 감각 깊은 모션을 제어합니다.

* **할 일 완료(일정 체크) 축하 세레머니 & 대사/은은한 사운드 믹스**
  - 사용자가 플래너 일정이나 Todo를 마칠 때마다 Moni가 감격하는 대사를 출력합니다.
  - 동시에 귀를 피로하게 하지 않는 부드럽고 가벼운 무선 화음(C5-E5-G5-C6)을 소프트하게 울려 기쁜 성취 신호를 동반합니다.

## 🛠️ 기술 사양 및 실행

### 1. 전제 조건 및 개발 설치
```bash
# 디펜던시 설치
npm install

# 데스크탑 메인 프레임워크 구동
npm run dev
```

### 2. 가용 환경 변수 (.env)
```env
# Google Developer Console에서 제공한 최신 키 적용 가능 (미체결 시 자동 로컬 가상 챗봇으로 운전)
GEMINI_API_KEY=AIzaSyA...
```

모든 수정 내지는 패치 내역은 개발 소통 히스토리를 엄밀히 참조하여 안전하게 설계되었으며, 크래시 무결성과 정밀 컴포넌트 린킹 테스트를 수반하여 깔끔하게 빌드 완료되었습니다. 🐾✨
